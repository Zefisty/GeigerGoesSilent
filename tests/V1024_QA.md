# ZoneRPG: controlled UI rollback, survival alerts retained

## Reverted
More, Pause and Statistics are restored exactly from v10.2.3 commit eb935ce. Save returns to its original entry and label, without new placement rules. The optional expedition report returns to More. Header control experiments, forced two-column More layout and related CSS are absent. The manual-save engine action and prior navigation/quality tests also match v10.2.3.

## Preserved
Encyclopedia tabs, Statistics/Achievements grouping, compact map cards, map centering and all earlier systems remain intact. Game version stays 10.2.4 because survival alerts remain.

## Survival alerts
HP <=35% of final maximum, stamina <=20%, radiation >=65%, hunger/thirst >=80%. Anti-spam, recovery reset, grouped toast, loaded-save behavior and one managed expiry timer are unchanged from the current release. Regression compares the entire alert implementation against HEAD.

## Save system
Existing manual and automatic slots, migrations and load cards are unchanged. A click through game.js verifies that manual saving leaves the automatic slot byte-for-byte unchanged. Pause/Resume retains the encounter.

## Tests
The hotfix suite has 14 passing groups. More, Pause and Statistics HTML are compared directly with the v10.2.3 renderer, with and without a completed expedition. Obsolete placement/order tests are removed. v1024-results.txt is historical output from before this rollback.

Full regression: all 23 suites pass, 371 PASS groups. All 48 JS/CJS files pass node --check; git diff --check passes.

## Remaining issues
This patch has no real browser visual QA. Automated HTML/VM/CSS checks do not substitute for desktop/mobile screenshots. No commit or push.
