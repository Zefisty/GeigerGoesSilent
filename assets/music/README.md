# Музыка — Sajen

Оригинальные локальные файлы `.ogg`, `.mp3`, `.wav` или `.m4a` добавляются сюда.
Пути задаются в `music-config.js` для восьми состояний: меню, безопасный сектор,
исследование, ночь, опасность, бой, легенда, кульминация.

Сейчас треков нет. Игра использует прежний процедурный фон. Нет сетевых запросов
к музыкальным сервисам. Отсутствующий файл безопасно возвращает этот фон.
Музыка запускается после пользовательского действия; громкость и отключение
сохраняются с персонажем. В `config.js` Sajen указан только в роли «Музыка».
