# Аудит описаний предметов ZoneRPG

## Результат

Проверено 107 предметов, обновлено 74 описания. У всех предметов теперь есть уникальный непустой flavor-текст.

До правок: 3 группы одинаковых описаний (14 предметов), 11 описаний с числовыми эффектами, которые повторял форматтер, 4 оружейных описания повторялись как traitText. В новом UI параметры выводятся один раз из данных.

## Формат и механика

Короткое описание и отдельный абзац параметров. Общий `ZoneRPGUI.describeItem()` используется инвентарём, магазином и открытыми сведениями об артефактах в энциклопедии. Неизвестные артефакты не раскрывают параметры раньше изучения.

Голод, жажда и радиация описываются согласно знаку изменения. Health/stamina показывают восстановление или потерю. Экипировка показывает реальные ненулевые модификаторы, включая штрафы. Регенерация HP подписана как эффект исследования. Совместимость патронов определяется по `weapon.ammoType`; устаревший `effect.amount` не выдаёт пачку патронов и не показывается как награда.

Тест сравнивает все определения предметов и оружия с HEAD, исключая только description/traitText. Цены, вес, эффекты, редкость, слоты и оружейные параметры совпадают. Engine, save/state, CSS, toast, карта, PWA и manifest не изменены. Commit/push не выполнялись.
