# Geiger Goes Silent — полевой журнал и живая Зона

Дата: 16 октября 2026. Изменения оставлены в рабочем дереве, без commit/push.

## Реализованные этапы

### A — интерфейс и память вылазок

- После безопасного возвращения открывается закрываемый компактный отчёт. Закрытие не тратит время. Отчёт не восстанавливается поверх игры после загрузки.
- Глубина, время, встречи, бои/победы, приобретённая радиация, изменение денег, трофеи, лучшая находка, прогресс поручений и необычная встреча берутся из состояния игры.
- «Потери HP за действия» — сумма положительных изменений потери здоровья между началом и концом действия. Это не точный валовой урон, если одно действие одновременно лечит и наносит урон.
- Последние десять завершённых вылазок доступны через Энциклопедию → Вылазки. Есть копирование итогов обычным текстом; при запрете Clipboard API появляется поле для ручного копирования.
- До трёх активных поручений закрепляются, поднимаются в журнале и отображаются в существующей области целей. Завершённые задания снимаются с закрепления.
- Метки «НОВОЕ» для новых типов предметов, заданий, слухов и записей снимаются при открытии соответствующего раздела. Стартовые предметы не отмечаются новыми.
- Краткая обстановка и погода отражают реальные Living Zone modifiers, а не отдельную декоративную погоду.
- Имя игрока используется в важных репликах выборочно и экранируется в HTML.

### B — слухи, глубина и редкие находки

- Три слуха с реальным ограниченным по времени влиянием на поиск артефактов, мутантов и патрули. Учитываются целевая локация, игровой час и источник информации.
- 16% таких передач неподтверждённые: они имеют нулевой бонус и менее надёжный источник. Просроченная передача может обновиться в следующем посещении, но повторный XP за неё не выдаётся.
- Существующие затраты и опасность глубины сохранены. Добавлен умеренный бонус редкости находок; врагам не наращивается бесконечно HP.
- Четыре именных предмета используют существующую экипировку, модификаторы, торговлю и локальные иконки. Новое письмо — коллекционный предмет, а не фиктивный расходник.
- Личная хроника ограничена 40 важными записями. Повторные открытия не дублируют одну и ту же запись.
- Шесть редких одноразовых встреч, шесть коротких открываемых архивных фрагментов. Именная экипировка не попадает в обычный генератор артефактов.

### C — точечное расширение существующей симуляции

- Один существующий радист временно переезжает из Армейских складов на Кордон при существующем столкновении группировок. Его доступность и адреса квестовых действий используют общую проверку; после окончания события он возвращается.
- Обычная память NPC и отношения личных историй переиспользуются для подсказок доверия. Доверие торговца даёт скромную скидку; фракционные ограничения не обходятся.
- Помощь или отказ раненому замерщику оставляют разные флаги, репутацию и доверие. Только помощь открывает последующую передачу от группы.
- Выход с глубины 8+ может оставить ограниченный след для последующей одноразовой встречи. Нет симуляции всех выброшенных вещей.
- Два временных состояния на четыре игровых часа: помехи/усиленный фон и аномальная тишина. Влияют на существующие вероятности и среду, снимаются штатным игровым временем.
- Редкие контекстные реплики в населённых секторах, существующие звуковые эффекты для слуха, редкой находки, радиационного порога и возвращения. Новая аудиобиблиотека не добавлена.

## Что намеренно не расширялось

Не внедрялись свободная симуляция перемещений всех NPC, новые глобальные ветви провала старых квестов, сокрытие географии карты, случайные запреты использования предметов, физическая симуляция брошенного снаряжения. Для них потребовалось бы менять самостоятельные существующие системы. Старые общие NPC-контакты, используемые несколькими локациями, не удалены ради новой системы перемещения радиста.

- Ручной слот не изменяется чтением журналов/закреплением; автосохранение использует прежний отдельный слот. Отдельно исправлена возможность создать автосохранение при открытии настроек из стартового меню.

## Найденные при проверке проблемы

- Новые worldFlags первоначально отсеивались старым whitelist загрузки — добавлены только семь необходимых флагов.
- При полном рюкзаке редкая награда могла не поместиться после оплаты выбора — добавлена предварительная проверка до расхода ресурсов, доверия, флагов и завершения выбора.
- Восстановленное одноразовое событие могло не иметь seen-маркера — завершение также фиксирует его в существующем учёте.
- Продление слуха не должно давать повторный XP — награда только за первое знакомство с определением слуха.
- Проверка обычных NPC не должна убирать существующие контакты из других хабов — ограничение единственного места применяется к переезжающему радисту.
- В старом renderer энциклопедии обнаружено случайное обращение к переменным нового списка слухов — старый вспомогательный renderer восстановлен, новый блок остался в штатном notebook.
- Доза +0.4% в отчёте округлялась до +0% — отображение сохраняет десятые. Старые отчёты без новой статистики выводят «нет данных».
- Регрессионный тест сравнивал сериализованные объекты по порядку ключей. Теперь сравниваются данные объектов; сами данные сохранения не изменялись ради теста.

## Баланс и дальнейшая проверка

Максимальная вероятность находки артефакта остаётся 28%; правдивый профильный слух даёт +3.5 процентного пункта в своей локации. Дополнительное усиление редкости ограничено множителем 1.18. Скидка доверия — 1% за положительную ступень, максимум 3%; старые фракционные условия сохранены. Эффекты ложных слухов не складываются с правдивыми без ограничения.

Рекомендуется длительное игровое наблюдение за частотой шести редких встреч и экономикой новых наград: короткая QA не заменяет балансировку нескольких полных прохождений.
