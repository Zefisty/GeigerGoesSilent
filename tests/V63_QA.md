# ZoneRPG v6.3 — QA, 7 октября 2026

Изменения оставлены в рабочем дереве. Commit и push не выполнялись.

## Fixed

- Разделены терминальные Continue и Return: Continue вызывает обычное исследование, Return восстанавливает исходный сектор и очищает только временное состояние сессии.
- Исходная локация устанавливается один раз, сохраняется вместе с глубиной. Обязательные nextStage/nextEvent выполняются до нового поиска. Нет промежуточного рендера idle; нет бесплатного повторного поиска.
- При нехватке 12 выносливости Continue не начинает поиск; Return доступен, после него доступна обычная передышка. Пустой поиск тоже имеет обе кнопки, но не даёт XP.
- Устранена потеря известности текущего/посещённого сектора при загрузке. Схема 8 объединяет known, visited и current; для старой вылазки без origin использует валидный текущий сектор, не Кордон. Исправление обычного Return не зависит от fallback для повреждённого location ID.
- Награда XP за завершение определения события в одном секторе выдаётся один раз. Для новостей ключ стабилен при новых переходах. Результат и флаги сохраняются; законный опыт за новые бои сохранён.
- Исправлена проверка сдачи доставки до списания предметов; прогресс доставки в журнале вычисляется по реальному запасу. Кнопка сохранения доступна прямо в событии.
- Консервы и человеческие изображения уже были исправлены в исходной локальной версии: проверено, что регрессии не появились.

## Map

21 достижимая локация, 37 уникальных двусторонних дорог, 74 реально выполненных движком перехода. Добавлена Кордон ↔ Мёртвая деревня. mapEdges отделяет граф путешествий от отрисовки, дедуплицирует пару ID; стрелка появляется только у явной односторонней связи. Синтетический тест подтверждает её сохранение. Текущие дороги все двусторонние. Маршрут Припять → Военные склады → Тёмная долина → Свалка проверен с save/load. «Южный проход» из ТЗ соответствует существующему southTunnel, «Южный тоннель»: новую дублирующую локацию не создавали.

## Replayability

Шесть предысторий: новичок и медик — Кордон; военный — блокпост; технарь — железная дорога; охотник — деревня новичков; мародёр — Свалка. Начальные секторы риска 1–2, прежние предметы и бонусы сохранены. У каждой истории своё вступление и специальный выбор. Малые стартовые изменения репутации, startingLocation, initialReputationModifiers и backgroundInteractions сохраняются как данные; загрузка не применяет бонусы повторно.

## Enemies

Добавлены стая тоннельных крыс, болотный ползун, панцирный секач, ночной прыгун и пепельный ходок: разные HP, урон, точность, защита, уклонение/подготовка тяжёлого удара/радиоактивные раны. Пулы учитывают сектор, глубину, ночь. Есть отдельные контекстные встречи, вступления, трофеи и пять локальных SVG. Артефактные трофеи новых мутантов имеют шанс 3–12%, не стандартные 60%. Каноническая привязка enemy ID → данные → visual сохранена, включая миграцию боя.

## Items

Набор инструментов многократный, открывает пять существующих технических действий. Из реального начального этапа проверены три: снять защёлку ящика (детали), настроить генератор (безопасная альтернатива), открыть сервисный проход (освобождение пленника и репутация). Расходники дают только объявленные эффекты; у консервов нет скрытого +8 stamina.

## Quest/UI

Единые статусы всех 23 заданий: Не выполнено / Выполняется / Готово к сдаче / Выполнено. Маршрутные и visit-задания используют общие правила и локализованные цели; поясняется автоматическое завершение по прибытии. Ручная сдача требует присутствия заказчика. Станция и городская разведка не являются особыми исключениями рендера.

## Browser

Настоящий Codex In-app Browser, локальный HTTP-сервер. Тестовая страница загружает реальные production-модули и обработчики кнопок; воспроизводимые состояния и RNG находятся только в tests/, сохранения изолированы в sessionStorage. Основной index.html также пройден отдельно, без fixture и фиксированной случайности.

Проверено через кнопки:

- Карта целиком: 1366×900 и 390×844; 37 линий, 0 лишних marker-end, нет горизонтального переполнения; подписи Свалки и Тёмной долины различимы. На узком экране используется прежняя сетка секторов.
- Военные склады: три поиска через два Continue, глубина 1→2→3, выносливость 100→88→76→64, Return в Склады, origin очищен.
- Тёмная долина: два поиска, сохранение прямо из события, reload/load, глубина 2 и origin сохранены, ещё Continue и Return в Долину.
- Южный тоннель: исследование, Return, карта, уход на Кордон, возврат, save/reload/load. Сектор остаётся известным.
- Новости на Складах дважды: слух показан оба раза, XP остаётся 8. Автоматически — 12 повторений и изменение номера рейда.
- Три пути инструментов с начальных этапов; полезный результат и tools:1 остаётся.
- Реальные старты военного, технаря, мародёра; остальные три и все шесть спецдействий — автоматически. Особый позывной военного также пройден через UI с save/reload/load.
- Все 23 задания в журнале; статусы Последнего рубежа и Городской разведки; доставка аптечки показана 1/1, Готово к сдаче.
- Бандит на блокпосте: enemy-bandit.svg, человек. Болотный ползун: новый SVG, огонь, урон 11, заражение +3.9%, победа, продолжение события. Все 23 изображения врагов загрузились в галерее.
- Основная игра: новый технарь, вступление, исследование багажа, Continue сразу к другому событию, Return на железную дорогу; Console без ошибок.
- Локальный SVG favicon открыт и отрисован браузером, rel=icon и название вкладки проверены на index.html.

В игровых сценариях и чистой повторной вкладке Console и диагностические errors/warnings пусты. В первой служебной вкладке инструмент автоматизации выдал ошибку при попытке нажать клавишу на нефокусируемом img галереи; эту операцию заменили обычной прокруткой, диалог/сохранение повторили в чистой вкладке без ошибок. Ошибка игры не воспроизвелась.

В проверенных сценариях игровых ошибок не осталось. Не проверялись реальные Safari/Firefox/Android/iOS, многочасовой баланс новых встреч и публичный GitHub Pages после публикации. Мобильная проверка выполнена изменением viewport настоящего браузера, не на физическом телефоне. Редкие встречи проверялись воспроизводимыми сценариями и движком, не ожиданием случайного появления в долгой сессии.
