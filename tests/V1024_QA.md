# ZoneRPG: header and More controls hotfix

## UI
Header already had no Save/Pause controls in the current working tree; it is unchanged. Tests compare its HTML with stable v10.2.3 across play, More, Pause, inventory, character and map. No header-specific Save/Pause CSS exists.

More contains six controls: encyclopedia, statistics/achievements, settings, credits, Save, Pause. The final pair is Save left, Pause right. Existing button styles are retained. A scoped grid rule preserves two columns below the global mobile breakpoint. The optional expedition report remains accessible inside statistics, preventing a seventh More box.

## Save and Pause
Save uses the existing manual writer and sets the existing feedback record to show "Игра сохранена вручную." A click through game.js verifies zonerpg_manual_save, unchanged autosave bytes and the visible toast. Pause/Resume retains the encounter and its existing game logic.

## Survival alerts
HP <=35% of final maximum, stamina <=20%, radiation >=65%, hunger/thirst >=80%. Anti-spam, recovery reset, grouped toast, loaded-save behavior and managed expiry are unchanged. Regression compares the complete survival alert implementation against HEAD.

## Tests
All 23 regression suites pass: 372 PASS groups, including 15 targeted groups. All 48 JS/CJS files pass node --check; git diff --check passes. All other four More actions and the expedition report are checked. Historical v1024-results.txt describes an older run.

## Remaining issues
No real browser visual QA was performed for this patch. Automated HTML/VM/CSS checks do not substitute for desktop/mobile screenshots. No commit or push.
