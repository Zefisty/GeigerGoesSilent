# ZoneRPG v10.2.2 QA

## Implementation
- Shared map-content transform computed from all rendered node border boxes. A uniform scale is applied only when required for 12px padding. Coordinates and graph edges remain unchanged.
- ResizeObserver resets the previous transform before measuring, then recomputes anchors; closing the map disconnects it.
- Independent localStorage keys: zonerpg_autosave / zonerpg_manual_save. Both use schema 15 and the existing sanitizer.
- Existing zonerpg-pda-save is copied exactly to both slots when neither new slot exists. The original remains as a backup. Initialization marker prevents deleted slots being recreated from that backup.
- Manual save and loading either slot never write the other slot.
- Autosave occurs once after a successful gameplay action changes state: travel, exploration/event progression/return, combat turns, inventory/equipment changes, trade, rest, quests, story/faction/world actions, starting a character. Failed/no-op actions, navigation, rendering and death do not write it.
- Main menu and death screen offer explicit save selection with location, level, rank, background and local timestamp.
- More removes local people action; location screen retains it. Slot deletion is separate.
